# Audio Engine

> [!NOTE] Currently in development and not all feature are implemented yet

This is a bare bones audio mixing engine designed to be lightweight, efficient, and run in the terminal

Phase one functionality is to be able to read audio input from a file, read input samples from an input decice, sum them together with individual level control, and pass audio to an output device

## Core Philosophies

- Zero Dependencies
- Basic C++, no templates, macros or other fancy add ons
